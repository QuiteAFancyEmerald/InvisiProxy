{{mask}}{{What is this project about?}}

{{mask}}{{ This project was an attempt to create an open-source solution for bypassing web filters, country restrictions and restrictive networks without needing to download a VPN. Source wise this legacy repository was intended to not utilize any frameworks focusing on a more manual approach. With the new rewrite featured on all the official services we moved over to SolidJS, Vite, and TypeScript with Fastify to allow for a more modern approach to development.}}
{{mask}}{{The rewrite is also intended to be more secure and easier to maintain.}}
